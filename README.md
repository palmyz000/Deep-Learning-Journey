## 📖 About This Repository

Welcome to my **Deep Learning Journey**! 🌟

This repository is my personal laboratory for exploring **Deep Learning**, specifically focusing on **Computer Vision (CV)** and **Natural Language Processing (NLP)**. Unlike general ML, this collection focuses on:
* **Neural Network Architectures:** Implementing CNNs, Transformers, and Transfer Learning.
* **Medical AI:** Leveraging Deep Learning for diagnostic assistance (Image Classification).
* **NLP & Sequence Modeling:** Analyzing and classifying text data for real-world scenarios.

It contains individual notebooks and scripts categorized by learning topics, serving as a cookbook for various DL techniques.

---

## 📂 Repository Structure

The projects are organized by the type of dachine learning problem:

### 🖼️ 1. Computer Vision (Medical Image Classification)
Experiments involving Convolutional Neural Networks (CNN) and Transfer Learning to assist in medical diagnostics.
* **🧠 Brain Tumor Classification:** Detecting and classifying brain tumors from MRI scans using Deep Learning models.
* **🩺 Skin Diseases Classification:** Classifying various skin conditions from clinical images to aid in early dermatological screening.

### 📝 2. Natural Language Processing (NLP)
Projects focused on text understanding and classification.
* **🚨 NLP Disaster Tweets:** Analyzing Twitter data to distinguish between real disaster announcements and metaphorical language using NLP techniques.

## 🚀 How to Use

1.  Clone this repository:
    ```bash
    git clone https://github.com/palmyz000/Deep-Learning-Journey.git
    ```
2.  Navigate to the project folder:
    ```bash
    cd Deep-Learning-Journey
    ```
3.  Install dependencies (if listed in a specific folder) or ensure you have the standard data science stack installed.
4.  Launch Jupyter Notebook:
    ```bash
    jupyter notebook
    ```
